## حدود العمل

استُخدمت بيانات صناعية وقواعد SQL مؤقتة فقط، وحُذفت بعد الاختبارات. لم يُشغّل مسار Program أو مهيئ الحسابات، ولم تُستخدم حسابات فعلية أو يُرسل بريد SMTP. لا تحتاج هذه الإصلاحات إلى ترحيل جديد لمخطط قاعدة البيانات.

لم تُختبر طابعة أو كاميرا فعلية، ولم تُنفّذ جولة يدوية كاملة لكل شاشة داخل المتصفح أو اختبارات حمل شاملة. اختبارات الويب الجديدة تشغّل الوحدات ومكونات React الأصلية مع محاكاة حدود الشبكة والمتصفح؛ تؤكد البيانات وتسلسل العرض والطباعة، ولا تؤكد إخراج جهاز طباعة بعينه.

فجوات استكمال المنتج المذكورة في قسم «فجوات وصول الميزات إلى الويب» في المراجعة الأصلية — مثل واجهات الاسترداد والمصروفات وإدارة عقود الرعاية — تبقى أعمال تطوير مستقلة؛ ليست ضمن الملاحظات الـ19 التي عولجت هنا.
