# تنفيذ إصلاحات مراجعة المشروع — 8 أكتوبر 2026

نُفّذت تغييرات الخادم والويب وتطبيق سطح المكتب، وطُبّق ترحيل قاعدة المشروع المحلية.

| ملاحظة المراجعة | المعالجة |
| --- | --- |
| 1. تعطل السداد والإلغاء | تحديث الكيانات المتتبعة دون تعليم جميع حقول الفاتورة بالتعديل، مع استمرار حماية قيم الفاتورة الصادرة. السداد يتطلب إصدار الفاتورة. |
| 2. حذف خدمة الحجز | حذف السجلات صراحة وربط بند الفاتورة بمعرف خدمة الحجز. الترحيل يربط البنود التاريخية عندما يكون التطابق وحيدًا. |
| 3. جمع العملات والتحصيل الجزئي | إجماليات الويب تعتمد اللقطات بالعملة الأساسية، مع فصل العملات الأساسية المختلفة، وإظهار صافي التحصيل واستبعاد المسودات والملغى. |
| 4. قيمة الفاتورة الأساسية القديمة | إعادة حساب القيمة الأساسية عند تعديل البنود، وتصحيح القيم المشتقة التاريخية في الترحيل. |
| 5. دمج أجنحة بموقع آخر | التحقق من موقع القاعة والمعرض عند الدمج، ومن أعضاء الدمج عند الحجز. |
| 6. اعتماد حجز ملغى | منع الانتقال من الملغى إلى المؤكد ومن المؤكد إلى الانتظار. الإلغاء مع دفعات يتطلب تسويتها. |
| 7. استمرار رموز الوصول القديمة | رمز الوصول مرتبط بجلسة التحديث وبختم أمان المستخدم؛ التحقق يشمل نشاط المستخدم والجلسة وصلاحياته الحالية. |
| 8. مؤسسة موقوفة | رفض الدخول والتجديد والطلبات المحمية للمؤسسة الموقوفة، وإلغاء جلساتها عند الإيقاف. |
| 9. تغيير العملة الأساسية | منع التغيير بعد وجود معاملات مالية، بما فيها السجلات المحذوفة ناعمًا، ورفض تقارير تجمع لقطات أساسية مختلفة. |
| 10. تجاهل الاستردادات | حساب مالي موحد لصافي المدفوع والرصيد بعد الإشعارات والاستردادات. |
| 11. الإجمالي المعدل صفرًا | حفظ الصفر كما هو واستخدام رصيد الخادم؛ إظهار الإشعارات والاستردادات في تفاصيل الفاتورة والطباعة. |
| 12. حالات الواجهة | توحيد Draft وIssued وPartiallyPaid وPaid وCancelled، واشتقاق التأخر من الاستحقاق والرصيد؛ تصحيح Confirmed في صفحة الحجوزات. |
| 13. تقريب التحويل الوسيط | ضرب الأسعار ثم تقريب المبلغ النهائي فقط، واستخدام دقة سعر الصرف المخزنة. |
| 14. قواعد الخدمات غير الصالحة | التحقق من السعر والفئة والعملة النشطة وتواريخ الصلاحية، وإضافة قيد يمنع السعر السالب. |
| 15. أولوية قواعد الخدمات | اختيار أحدث قاعدة بعد خصوصية المعرض والفئة، مع حسم حتمي بالتاريخ والمعرف. |
| 16. الدمج العام ومساحته | العضوية والتوفر خاصان بالمعرض، مع فهرس فريد يمنع عضويتين للجناح في المعرض نفسه؛ الدمج الجديد يستخدم المساحة الحالية. |
| 17. مؤشرات اللوحة | الإشغال من الحجوزات الفعلية في المعارض المفتوحة، والتحصيل الشهري حسب تاريخ الدفعة والاسترداد. |
| 18. تطبيق سطح المكتب | إرسال الخدمات مع إنشاء الحجز في طلب واحد واستخدام العملة المفضلة للشركة وعملة سعر الخدمة. |
| 19. مساحات الرعاية المحجوزة | تحرير التخصيصات عند إلغاء العقد أو اكتماله أو حذفه داخل معاملة واحدة، ومنع تخصيص مساحة لعقد مغلق. |
| 20. المصروفات غير المحولة | محاولة تحويلها بالسعر التاريخي؛ التقرير يرفض الاكتمال إذا لم يتوفر السعر بدل احتسابها صفرًا. |
| 21. فئة المنتج | مصدرها الموثوق قطاع الشركة العارضة، ويُمرّر إلى اختيار قاعدة التسعير. |
