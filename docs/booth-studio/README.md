# استوديو الأجنحة

المسار الفعلي: `/booths/designer?hallId=ID`.
المعاينة التجريبية: `http://127.0.0.1:53513/booths/designer?hallId=1`.

## ما تم تنفيذه

- تصميم مباشر: رسم مستطيلات ومضلعات، تحريك وتدوير وتغيير المقاس، تحرير الزوايا، تحديد متعدد، أوامر سياقية، تراجع وإعادة.
- أدوات هندسية: صفوف بالمقاسات والممرات المطلوبة، ترقيم متسلسل، محاذاة وتوزيع، تجميع، تقسيم ودمج هندسي للأجنحة المتاحة المتلاصقة.
- عناصر القاعة: ممرات ومناطق محظورة وأعمدة ومداخل ومخارج، خطوط ونصوص وقياسات ورسم حر.
- حدود القاعة مأخوذة من مخطط الموقع المرتبط بسجل القاعة. القاعات المقعرة والزوايا لا تتحول إلى مستطيل.
- حفظ الأجنحة بمعرفاتها الموجودة، مع الاحتفاظ بحالة الحجز وقاعدة التسعير. الأجنحة المحجوزة والمندمجة مقفلة هندسياً.
- الأجنحة القديمة التي تفتقد المقاسات أو المواقع تظهر بانتظار التوزيع؛ يجب اعتماد مقاسها وموقعها قبل الحفظ.
- حساب المساحة والتداخل حسب المضلع الفعلي على الواجهة والخادم، مع منع تجاوز الحدود أو اختراق الجدران والأعمدة والممرات.
- حفظ يدوي، استعادة مسودة محلية لكل مستخدم وقاعة، تحذير مغادرة، حماية من تعارض الحفظ، وتصدير SVG وطباعة.

الدمج والتقسيم الهندسي يستبدلان سجلات الأجنحة المتاحة عند الحفظ؛ يرفض الخادم حذف سجلات مرتبطة بحجوزات أو عمليات دمج. يبدأ سجل التراجع من النسخة الجديدة بعد نجاح الحفظ.

## التشغيل والتحقق

- أعد تشغيل الـ API لتفعيل التحقق الهندسي ونسخة الحفظ الجديدة. لا يتطلب هذا التغيير ترحيلاً جديداً لقاعدة البيانات.
- من مجلد الواجهة: `npm run build`، `npm test`.
- اختبارات الخادم: `dotnet test ExhibitionManagementSystem.Api.Tests/ExhibitionManagementSystem.Api.Tests.csproj -c Release --filter "FullyQualifiedName~Booth|FullyQualifiedName~Venue" --no-restore`.
- المعاينة تستخدم بيانات تجريبية مستقلة في المتصفح. اختبارات المعاينة لا تكتب إلى قاعدة البيانات الفعلية.

تم التحقق عملياً من إنشاء الصفوف، التقسيم، الترقيم، الدمج، رسم جناح L، تحرير زواياه، التراجع، الحفظ وإعادة التحميل، واستعادة المسودة وتعارض جلستين. لقطة التعارض موجودة في `conflict.jpg`.
